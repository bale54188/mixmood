# 配方与材料数据

`recipes.json` 为 Milestone 2 正式使用的 18 款经典配方；17 款参考 IBA，Gin & Tonic 参考 Sipsmith 官方配方。逐款来源与核对说明见 [SOURCES.md](SOURCES.md)，每条记录也包含原始来源链接和核对日期。配方步骤为自行撰写的中文简述，不使用来源图片或整页文本。

`ingredients.json` 是材料及别名字典。ID 为匹配键；中英文名与别名由 MoonBit 统一解析。青柠与鲜榨青柠汁采用同一个材料键，是否能榨出足够汁液由用户自行确认。苏打水与汤力水、干味美思与甜红味美思、方糖与糖浆保持不同；不进行未被配方允许的替换。波本/黑麦仅在 IBA 明确允许的两款配方中列为替代选项。

- `amount`：来源给出的数字；`null` 表示来源未量化，配合 `unit` 与 `amount_note` 解释，绝不猜测毫升数。保留茶匙、吧匙、dash、份等原单位。
- `optional`：当前只有 Margarita 的盐口为可选；不影响主体配料齐全的判断。
- 装饰单列于 `garnish`，不参与主体材料匹配。匹配包含已列明的冰和饮用水，不默认用户拥有它们。
- `difficulty` / `minutes` / 口味标签为 MixMood 编辑整理，其中难度与制作时间为估计，不冒充来源给出的数据；时间不含备料、制冰、糖浆制作。
- French 75 的 IBA 方法未列冰或制冷量，按其原步骤收录并提示预冷，不虚构制冷用量；推荐不会检查工具和冷却条件。
- 仅判断材料有无，不计算剩余数量、酒精度或可制作杯数。

`recipes.example.json` 的 3 条 M1 示例只用于兼容性测试，不在正式首页或酒柜中使用。
